How it works

From idea to live URL in under a minute.

01

You do one thing

Check your email, copy the six-digit code, paste it to your AI. That's it. You're done.

02

Your AI gets access

A key arrives in the response body — no dashboard to open, no settings page, no redirect to click through.

03

A URL is ready instantly

A globally-unique address is auto-generated. Custom names available on paid plans.

04

Your site goes live

Upload HTML, CSS, JS, and images. The whole site is on the internet within a second. No build step.

agent shell  
# 1. Request a code
curl -X POST https://api.itslive.dev/signup \
  -d '{"email":"you@example.com"}'
→ "Check your email for a code."

# You paste: AH7X2K9
curl -X POST https://api.itslive.dev/verify \
  -d '{"email":"you@example.com","code":"AH7X2K9"}'
→ {"api_key": "il_live_..."}

# 2. Create a site
curl -X POST https://api.itslive.dev/sites \
  -H "X-API-Key: il_live_..."
→ {"url": "https://violet-crane-42.itslive.dev"}

# 3. Publish your site
curl -X PUT https://api.itslive.dev/sites/violet-crane-42 \
  -H "X-API-Key: il_live_..." \
  --data-binary @mysite.zip
✓ Live at https://violet-crane-42.itslive.dev
