How it works

From nothing to live
in four API calls.

The human's only job is to paste a 6-character code. Everything else is the agent's.

agent shell
# Step 1: Sign up (agent asks for user's email)
curl -X POST https://api.itslive.dev/signup \
  -d '{"email":"you@example.com"}'

# → "Check your email for a code."
# User pastes: AH-7X2K9

curl -X POST https://api.itslive.dev/verify \
  -d '{"email":"you@example.com","code":"AH7X2K9"}'

# → { "api_key": "il_live_..." }

# Step 2: Create a site
curl -X POST https://api.itslive.dev/sites \
  -H "X-API-Key: il_live_..."

# → { "url": "https://violet-crane-42.itslive.dev" }

# Step 3: Deploy HTML
curl -X PUT https://api.itslive.dev/sites/violet-crane-42 \
  -H "X-API-Key: il_live_..." \
  --data-binary @dashboard.html

✓ Live at https://violet-crane-42.itslive.dev
1

Human does one thing

Receives an email, copies a 6-character code, pastes it back. That's the entire human workflow.

2

Agent gets an API key

The key is issued in the verify response. It starts with il_live_ and never needs to be refreshed.

3

Site is provisioned instantly

A globally-unique subdomain is auto-generated. No collision, no setup. Custom names available on paid plans.

4

Deploy is a single PUT

Upload one file or a multi-file site. The content is live on Cloudflare's global edge within 1 second. No build step. No CI.

Features

Everything agents need.
Nothing humans don't.

⚡

Sub-second deploys

A deploy is a PUT to R2. No build pipeline. No queue. The file is served the moment Cloudflare confirms the write.

🌍

Global edge, zero egress

Sites served from 200+ Cloudflare edge locations. R2 storage has zero egress fees — traffic is always free.

🔐

Password protection

Platform-level password gating via PBKDF2 sessions. Agents set it via one API call. Visitors see a clean login form.

🗄️

Dynamic sites (Builder+)

Auto-provisioned SQLite database per site. Agent deploys a worker-routes.json to define API endpoints. No backend code to write.

🔑

No OAuth. Ever.

API keys in response bodies, not behind redirect flows. Every action available via curl. Agents don't navigate HTML.

🛡️

Secure by default

Security headers injected on every response. Keys stored as SHA-256 hashes. Timing-safe comparisons. Path traversal prevention.

📁

Multi-file sites

Upload HTML, CSS, JS, images, fonts — all in one multipart PUT. SPA routing via index.html fallback. Atomic deploys.

🌐

Custom domains (Builder+)

Bring your own domain, CNAME it, SSL auto-issued via Cloudflare for SaaS. Your agent handles the whole setup.

📊

Machine-readable errors

Every error has a code field. Rate limit state queryable via GET /usage. No screen-scraping required.
