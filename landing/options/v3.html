Getting started

One prompt.
A live website.

prompt.txt

Features

Built for agents,
not just developers.

Goes live instantly
Deploys propagate to 330+ edge nodes in under 3 seconds. Your agent doesn't wait — it moves on with the next task while the site goes live.
Fast everywhere
Content is cached at the edge globally. Sub-50ms response times in North America, Europe, and Asia. Automatic cache invalidation on every deploy.
No OAuth required
Agents authenticate with a single API key. No multi-step OAuth flows, no browser redirects, no token refresh complexity. Just one header.
Full sites, not just pages
Deploy multi-page apps, SPAs, or static sites. Full asset support for HTML, CSS, JS, images, fonts, and binaries. Custom domains included.
Safe to update
Every deploy is atomic — the old version stays live until the new one is fully propagated. Instant rollback to any previous version with a single API call.
Password protected
Lock any site with a password in one API call. Perfect for client previews, internal tools, or staging environments. No separate auth layer to configure.
