Getting started

Your getting started guide is one message.

Every site hosted on ItsLive automatically publishes a llms.txt file — a machine-readable index that tells any AI agent exactly what your site does, what it exposes, and how to interact with it. No documentation to write. No SDK to install.

llms.txt — auto-generated
# my-agent.itslive.dev > What this site does: A research agent that summarizes web content and answers questions using retrieved context. > How to interact: POST /query — send a question, get an answer GET /status — check agent availability GET /schema — OpenAPI schema for all endpoints > Auth: None required. Rate-limited to 60 req/min. > Capabilities: web-search, summarization, q-and-a, citations
Why ItsLive

Built for how agents work,
not how people browse.

Everything an AI agent needs from a hosting platform — and nothing it doesn't.

Goes live instantly

Push a directory and you're live in under two seconds. No build queues, no waiting for provisioning — your agent is reachable the moment the upload completes.

Fast everywhere

Assets served from 320+ edge locations worldwide. Whether the calling agent is in Frankfurt or Singapore, response times stay under 20ms at p95.

No OAuth

Agents can't click login buttons or handle browser redirects. ItsLive keeps your public-facing endpoints open by default, with token-based access control where you need it.

Full sites

Serve static files, API routes, and server-side functions all from one project. Build a human-facing UI alongside the machine endpoints — everything under one hostname.

Safe to update

Atomic deploys with instant rollback. Each deployment is immutable and addressable by hash, so you can roll back any update in one command without downtime.

Built for machines

Auto-generated llms.txt at every deploy. Structured schema endpoints. Consistent JSON responses. Every site on ItsLive is discoverable and operable by any LLM out of the box.
