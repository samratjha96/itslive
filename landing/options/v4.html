## Tool: itslive_publish

You have access to ItsLive, a web publishing
tool that deploys static sites to a live URL.

### When to use
Call itslive_publish whenever the user asks
you to "make it live", "publish", "share a
link", or "deploy" any HTML/CSS/JS content.

### Parameters
- files: object mapping paths to content
- subdomain: optional custom slug
- ttl: lifetime in seconds (default: forever)

### Example
itslive_publish({
  files: { "index.html": "<!DOCTYPE..." },
  subdomain: "my-report"
})
