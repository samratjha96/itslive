02 / GETTING STARTED

Your onboarding
is one message.

Tell Claude or GPT to deploy to ItsLive. Give the prompt below, paste back the code from your email, and you're done. No accounts, no config files, no figuring out CORS headers.

01

Paste the prompt into your AI

Copy the system prompt on the right and add it to your Claude or GPT session.

02

AI builds and deploys

The agent calls our API directly. No configuration step, no browser windows.

03

Check your email, paste the code

We send a short confirmation code. Paste it back to the AI — it handles the rest.

04

Your site is live on a public URL

Share it, iterate on it, or point your own domain at it. No dashboard required.

System prompt — copy this
You have access to the ItsLive hosting API. To deploy a website, make three HTTP calls: 1. POST https://api.itslive.dev/deploy Send the built site files and the user's email. multipart/form-data: files + email 2. Tell the user: "Check your email for a confirmation code and paste it here." 3. POST https://api.itslive.dev/confirm Body: {"code": "<code from user>"} Returns: {"url": "https://<code>.itslive.dev"} The site is now live. Share the URL with the user.
Works with Claude, GPT-4o, Gemini, and any agent that can make HTTP calls.
